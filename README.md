# The AI-Powered Interaction Builder

An interactive JavaScript greeting application built with HTML, CSS, and vanilla JavaScript.

## Features

- Accepts a user's name and time of day.
- Generates a personalized welcome message when the button is clicked.
- Uses `day` as the default time when no time is provided.

## Usage

1. Open `index.html` in a web browser.
2. Enter a name.
3. Enter a time of day, such as `morning`, `afternoon`, or `evening`.
4. Select **Generate Greeting**.

The app displays a message in this format:

```text
Good morning, Alex! Welcome back to JavaScript class.
```
